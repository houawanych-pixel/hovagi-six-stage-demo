# HOVAGI — Six Stage Mission (graybox demo, web build only)

Play: https://houawanych-pixel.github.io/hovagi-six-stage-demo/

This is the one public build. It is not hosted anywhere else.

This repository holds ONLY the exported web build. Source:

- Repo: https://github.com/houawanych-pixel/chronicle-clash-mg3d
- Branch: `hovagi-fps` (project in `six_stage/`); see `version.txt` for the exact commit and hashes.

v1.1 (Stage 01 update): clean low-poly Stage 01 map, close chase camera, AIM/LOWER toggle, big START
button, green objective guide, fixed walking animation. Details: `six_stage/docs/stage01_clean/CHANGES.md`.

v1.2 (first-person shooter mode): tap 1ST (or O) for a Call of Duty-style first-person view — move and look together, hip fire, ADS aims down sights, recoil, spread, head shots, hit markers. 3RD goes back to the stealth camera. Details: `six_stage/docs/fps/CHANGES.md`.

Exported with Godot 4.3 (Web preset, single-threaded, Compatibility renderer). Graybox prototype; not a
finished or phone-certified release.
